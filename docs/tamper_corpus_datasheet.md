# Tamper corpus datasheet

The structural corpus is generated by `scripts/generate_tamper_corpus.py` with seed
`2026092601`. It creates small GGUF-like and safetensors-like model bundles for dev and
test splits. Each bundle contains a model artifact, tokenizer, config, signed Merkle manifest,
model bill of materials, and case metadata. Generated private keys, signatures, and artifacts are
local outputs and are not required in source control.

The verifier receives only artifact bytes, manifests, model bill of materials files, signatures,
and trusted keys. The case label fields are used only after verification for reporting detection
rates.

Covered test tamper classes are: single-bit weight flip, single-bit header flip, tensor swap,
architecture edit, tokenizer edit, chat template injection, truncation, append, same-name model
substitution, signature stripping, untrusted signature, model bill of materials entry drift,
dependency swap, and rollback to an older signed version.

Run:

```powershell
python scripts\generate_tamper_corpus.py --out corpus\tamper-corpus
```
